# 💱 Currency Converter

A simple, responsive, and interactive **Currency Converter Web Application** built using **HTML, CSS, and JavaScript**. The application allows users to enter an amount, select the source and target currencies, and instantly calculate the converted amount using exchange-rate data.

## 🚀 Features

- 💰 Convert between multiple currencies
- 🔄 Select source and target currencies
- ⚡ Instant conversion using JavaScript
- 🌐 Exchange-rate API integration
- 📱 Responsive design for desktop and mobile devices
- 🎨 Clean and user-friendly interface
- 🔁 Easy currency selection and conversion
- ⚠️ Basic input validation and error handling

## 🛠️ Technologies Used

- **HTML5** – Structure and layout
- **CSS3** – Styling, responsiveness, and UI design
- **JavaScript (ES6+)** – Application logic, API requests, and DOM manipulation
- **Exchange Rate API** – Provides currency exchange-rate data

## ⚙️ How It Works

1. The user enters the amount they want to convert.
2. The user selects the **source currency**.
3. The user selects the **target currency**.
4. JavaScript sends a request to the exchange-rate API.
5. The application retrieves the latest available exchange rate.
6. The amount is converted using:

```text
Converted Amount = Amount × Exchange Rate
```

7. The converted value is displayed dynamically on the webpage.
